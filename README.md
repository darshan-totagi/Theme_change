# React Theme Context App

This is a simple React app demonstrating how to use the Context API to toggle between light and dark themes. It includes:

- ThemeContext using React's `createContext`
- A toggle button to switch themes
- Styling using both inline styles and external CSS
- A sample background image
- Nested component (`Child1`) that consumes the them


## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed
- Vite development server (or create-react-app if you prefer)

### Installation

```bash
npm install
npm run dev
